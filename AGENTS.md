# Project Rules

## Project Goal

This project designs and implements a local-first posture-and-training app for individual use. The app should prioritize safety, posture, fat loss, muscle gain, then conditioning.

## Current Phase

The current phase is implementation planning. Do not implement app code until the implementation plan is reviewed and approved.

## Directory Rules

- `docs/superpowers/specs/`: approved design specs.
- `docs/superpowers/plans/`: implementation plans.
- `.superpowers/`: temporary visual brainstorming mockups and state.
- App code should not be added until the spec and implementation plan are approved.

## Privacy Rules

- Do not copy body photos into the repository.
- Do not commit private photos, real health profiles, names, birth data, local usernames, secrets, API keys, or credentials.
- Documentation and tests must use clearly synthetic, non-identifying examples.
- Treat posture and health notes as private local project data.

## Training Safety Rules

- This app is not medical diagnosis or treatment.
- Do not hard-code a real user's diagnosis, imaging result, symptoms, body measurements, or exercise performance in source code or documentation.
- Training recommendations should prioritize conservative progression, pain feedback, core stability, hip control, and avoiding aggressive loading when pain or fatigue is high.
- Red-flag symptoms require stopping the generated plan and seeking appropriate medical assessment; the app must not diagnose or treat a condition.

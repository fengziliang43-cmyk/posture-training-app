# 只读钥匙与导出接口规范

## 目标

让用户给自己的仪表盘（例如项目负责人自用的「中控台」）开一把只读钥匙，仪表盘用它读几样训练汇总，不用保存账号密码，也不用每月重新登录。良 2026-11-17 定。

## 钥匙

- 在「我的 → 账号与隐私」里生成、查看、作废。每个账号最多 5 把有效钥匙。
- 钥匙原文只在生成那一次显示；服务端只存 SHA-256 指纹，不存原文。
- 钥匙只能调 `GET /api/export/summary`；别的接口一律不认它（照旧只认登录会话）。
- 作废后立即失效。注销账号时一并删除。备份导出不包含钥匙表。
- 每把钥匙每小时最多读 60 次。日志不记钥匙。

## 导出内容（只这些）

- 本周、本月完成主训练的日期；本周的周复盘建议（maintain / reduce / recover / eligible-for-progression）。
- 最近 14 天每天的腰背不适、颈肩不适（0–10）、精力（1–5）、当天有没有记危险信号（只给有或没有，不给是哪一项）。
- 最近一次训练档位调整的日期和原因。

不导出：体态照片、训练档案、备注、体重、睡眠、步数、DeepSeek 设置、账号信息。

## 边界

- 导出只读，不改任何数据。
- 危险信号的判断和停训规则不变；导出只是告诉仪表盘「那天记过」，仪表盘不得据此给医疗建议。
- 推送、合并、部署、改线上数据库各需良单独同意。

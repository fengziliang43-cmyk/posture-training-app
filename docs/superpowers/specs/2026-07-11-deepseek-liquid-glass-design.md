# DeepSeek AI 教练与 Liquid Glass 设计规范

## 目标

让已接入的 DeepSeek 在手机首页成为可见、可理解、可重试的 AI 教练模块，同时保持本地训练规则的唯一决策权；整体视觉采用暖象牙白、淡紫与冰蓝环境光的克制液态玻璃风格。

## 不可突破的边界

- DeepSeek 只解释本地规则已经生成的训练和周复盘，不新增动作、不改组数次数、不做医疗诊断。
- 体态照片只用于人工同角度对比，永不发送给 DeepSeek。
- API Key 只写入 Mac，本机设置接口只返回“已配置 / 未配置”，不回显任何 Key 字符。
- 红旗症状出现时，今日页只显示停训与就医评估建议，不显示 AI 解读、替代训练或可执行动作。
- 已完成的训练计划是历史记录；同日后续状态更新不得覆写其训练类型和统计归属。

## 模块完整性

### 今日

- 状态填写：腰酸、精神、可训练时间和高级状态。
- 已有计划后仍可“更新今日状态或上报不适”。
- 今日判断与本地训练计划。
- 首页 AI 教练卡覆盖未配置/关闭、生成中、DeepSeek 成功、本地回退、失败重试，并显示来源与更新时间。
- 训练详情覆盖动作顺序、组数、次数/秒数、休息、要点、替代动作、停止条件、逐项完成。
- 全部动作完成后记录训练后腰酸，再提交训练。

### 记录

- 月历、日期详情、腰酸/精神/睡眠/体重趋势、训练统计与历史。
- AI 周复盘显示来源、生成中、本地回退、失败重试和更新时间；只总结，不改规则。

### 体态

- 正面/侧面/背面、最新/本月对比、透明度滑杆、上传、备注、时间流和空状态。
- 显眼展示“只做人工对比，不做 AI 或医疗诊断”。

### 设置

- 当前账号、本地 server 地址与连接测试、通知、本地备份。
- DeepSeek 开关、Key 状态、模型、保存 Key、测试连接、清除 Key、最近测试结果。

## 视觉规则

- 暖象牙白背景，以低饱和淡紫/冰蓝/淡桃环境光提供折射背景。
- 顶栏、AI 卡、AI 周复盘和悬浮底栏使用液态玻璃：`backdrop-filter`、内高光、半透明白边、柔和环境阴影和轻微色散。
- 普通内容卡优先可读性，不全部玻璃化。
- 圆角以 18–26px 为主；触控目标至少 44px。
- 底栏 active 项采用半透明凸透镜效果，固定中文“今日 / 记录 / 体态 / 设置”。
- 支持 `prefers-reduced-motion`，不依赖动画表达关键信息。

## 验收

- 390×844 视口无横向溢出，底栏不遮挡页面最后一个操作。
- AI 来源和回退原因不可混淆。
- 红旗阻断、训练完成后腰酸、历史计划不可覆写均有自动化测试或真实浏览器流程验证。

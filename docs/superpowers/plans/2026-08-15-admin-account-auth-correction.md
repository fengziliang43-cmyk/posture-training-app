# 独立管理员后台与账号能力纠正实施计划

1. 扩展认证标识校验，兼容原账号名与标准邮箱，并在认证响应中加入最小化 `role` 字段。
2. 把管理员仪表盘从 `MeView` 移到独立 `AdminConsole`，普通页面不再请求统计；`App` 只在 `/admin` 且当前角色为 admin 时渲染后台。
3. 为生产 Nginx 增加 `/admin` 的 `auth_request` 鉴权，沿用 active admin 探针并对普通用户返回 404。
4. 新增鉴权修改密码 API：验证旧密码、写入新 bcrypt 哈希、撤销全部会话并清 Cookie。
5. 在“账号与隐私”加入当前密码、新密码和确认密码表单，成功后返回登录页。
6. 把重复账号 409 映射成明确中文，把登录/注册字段改成“账号或邮箱”。
7. 更新体态页照片文案为服务器保存，并保持不发送 DeepSeek 与非诊断边界。
8. 补齐邮箱注册登录、大小写判重、密码轮换、管理员独立路径、普通入口消失和文案测试。
9. 运行相关测试、全量测试、lint、生产构建和移动端浏览器验收。
10. 只有获得新一轮 GitHub push 与生产部署授权后，才发布为下一版本并切换线上。
